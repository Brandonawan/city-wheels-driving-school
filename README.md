# City Wheels Driving School

Static-friendly Next.js landing page for City Wheels Driving School, 12 Etta Agbor, Calabar.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If that port is busy, Next.js will choose another available port.

## Production build

```bash
npm run build
```

The project uses Next.js static export configuration and is ready to deploy on Vercel.

## Deploy on Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Import the repository into Vercel.
3. Keep the default Next.js build settings.
4. Deploy.

No database or environment variables are required for the current demo. Replace the WhatsApp/call details in `app/page.js` if the school’s contact details change.
